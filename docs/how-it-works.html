How the brief works

A plain English tour of the logic. Back to today's brief

The short version

Every morning a robot (a GitHub Action) wakes up, reads 18 public threat sources, throws away old and duplicate items, adds context to each story, gives it a score out of 100, and publishes the result here and to your email. Then it adds a daily lesson.

When it runs

  • Every day at 05:17 UTC. That is 06:17 UK time in summer (BST) and 05:17 in winter (GMT).
  • Normally it looks back 36 hours, so nothing slips through the gap between runs.
  • On Mondays it looks back 72 hours to cover the weekend.
  • It takes about a minute. Then GitHub Pages republishes the site, which takes another minute or two.

Step 2: Clean

  • Strip formatting: HTML tags are removed so summaries read as plain text.
  • Fix dates: every feed writes dates differently, so all of them are converted to one format (UTC).
  • Time window: items older than the look-back window are dropped. KEV looks back 7 days because it updates less often.
  • Duplicates: the same link, or the same headline from two outlets, becomes one story. The other outlets are listed as also reported by.
  • Same bug, different stories: if two stories mention the same CVE, each counts as confirmation (corroboration) for the other.

Each threat type comes with a plain English meaning and next steps:

RansomwareCriminals lock (encrypt) or steal a company's files, then demand money.
PhishingFake emails, texts or calls that trick people into handing over passwords or money.
Data breachPrivate data got out. Stolen data is later reused for scams and account takeover.
Zero-dayA bug attackers found before the vendor could fix it, so there may be no patch yet.
Exploited vulnAttackers are already using this weakness in real attacks, not just in theory.
Supply chainAttackers break into a supplier or software package to reach that supplier's customers.
Nation-state / APTGovernment-backed hackers, usually after secrets, access, or disruption rather than quick cash.
MalwareMalicious software, for example info-stealers that grab saved passwords and cookies.
DDoSFlooding a website or service with junk traffic until it falls over.
Fraud / ScamTricks aimed at stealing money, often by pretending to be a trusted brand or person.
Identity / MFAAttacks on logins: fooling the help desk, stealing session cookies, or MFA fatigue.

Honest limits: this is keyword matching, not a human reading every article. It can miss things or tag them wrongly, for example a story about "BT" the company versus the letters BT. Leak-site claims come from the criminals, so treat them as unconfirmed. Always check the source before acting.

Worked example

NCSC warns UK organisations about an exploited VPN bug, posted 5 hours ago, also reported by BleepingComputer:

  • UK score: UK source 35 + NCSC 30 + UK 30 = 95 → 95 × 0.35 = 33
  • On KEV: 25
  • EPSS 94% → 19
  • Exploited bug is a serious threat type: 10
  • Official advisory: 8
  • 5 hours old: 15
  • One other outlet: 3
  • Total 113, capped at 100. It goes to the top.

The top 8 stories get full cards. If two stories are about the same CVE, only the higher one gets a card, so the list is not repetitive. Everything else goes into the searchable Everything else table.

Step 5: Publish

  • docs/index.html: the dashboard you are using (replaced each day).
  • docs/briefs/<date>.md and docs/latest.md: the short text brief.
  • docs/data/<date>.json: all the data, for your own tools.
  • The robot saves these files to the repo, GitHub Pages republishes the site, and the email goes out.

The knowledge pack

  • Lesson: 33 lessons, one a day in a fixed order, starting again after 33 days. Repetition is on purpose.
  • Reviews: lessons from 1, 3 and 7 days ago come back as quizzes. This is called spaced repetition: you see something again just as you would start to forget it, which makes it stick.
  • Word of the day: 40 terms, rotating the same way.
  • Drill: takes the highest-ranked story that has something to look up (a CVE, an indicator, or a UK ransomware victim) and turns it into a 15-minute step-by-step enrichment exercise.
